# Research report and demonstrations

Start with [the research report](final-report.md) and [the native evaluation demonstration](demo-native/index.html). Clone or download the repository and open the HTML locally; GitHub displays its source rather than running it.

`figures/` contains measured plots, input tables, and generation manifests. `archive-native-followup.md` and `case-study-c1.md` retain earlier, more detailed scientific narratives. `demo/` and `demo-final/` preserve earlier recorded demonstrations.

All demonstrations use saved records and perform no model, candidate, or network execution. Historical reports describe their own study versions; the current scope and reproduction instructions are in the repository README.
