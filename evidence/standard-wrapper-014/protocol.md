Freeze **24 cells**: two helper versions × two consumer policies (raw scheduler, fresh directory + actual zero exit + complete schema) × six modes. Modes: authored hard exit 7 or 0 inside the helper's sequential experiment; the same exit before helper entry; complete positive; complete negative. Each cell first runs a valid primer through its selected helper, then changes the authored initial program and evaluates once. There are 48 fixed evaluator processes, no retries, no model calls. A process has 15 seconds. Failed primers/worker infrastructure stop the experiment and remain preserved.

Both helper versions are loaded from exact preserved upstream files. The evaluator actually calls `run_shinka_eval`, with one sequential run, authored experiment/aggregation/validation functions, and no plots. It does not replace `save_json_results`, the result loader, or the oracle. The four termination modes are controlled faults, not naturally observed model actions. Moving the same termination across helper entry preserves the obligation not to accept evidence for the changed attempt; it probes a repair's applicability boundary, not functional equivalence of successful programs.
